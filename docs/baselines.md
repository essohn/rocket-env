# 베이스라인 측정 기록

등급 컷을 눈감고 정하지 않기 위한 기록이다. 라운드를 새로 만들거나 난이도를
조정할 때마다 `scripts/measure_baseline.py`로 다시 재고 여기에 덧붙인다.

측정 조건: 평가 40 에피소드, 시드 `10000..10039`, `deterministic=True`.
학습은 SB3 `DQN("MlpPolicy")`, `net_arch=[256, 256]`, `buffer_size=200000`,
`learning_starts=5000`.

## 왜 이 파일이 필요한가

**모든 정책이 같은 점수를 받는 환경도 모든 테스트를 통과한다.** 실제로 이
저장소는 165개 테스트가 전부 통과하는 상태에서, 무행동 정책이 실패 상한
40점 중 36.6점을 받고 학습된 DQN이 그보다 **낮은** 점수를 받는 환경을
만들어냈다. 단위 테스트도, exploit 회귀 테스트도 그것을 잡지 못했다 —
"꼼수가 이기지 못한다"는 검증했지만 "실력이 이긴다"는 아무도 검증하지
않았기 때문이다. 변별력은 재봐야 안다.

## 학습 예산에 대한 경고

**10만 스텝으로 재면 안 된다.** 그 예산에서는 모든 프리셋에서 DQN이 성공률
0%이고 무행동보다 낮은 점수를 받는다. 실제로 이 사실 때문에 "환경이 학습
불가능하다"는 잘못된 결론에 도달해 보상을 두 번 재설계했다.

학생이 Colab에서 30~60분 돌리는 것은 **50만~100만 스텝**에 해당한다.
측정은 그 예산으로 해야 한다. 10만 스텝은 코드가 도는지 확인하는
스모크 테스트용이지 성능 측정용이 아니다.

## n=1 측정의 함정 — 학습 시드도 재봐야 안다

**같은 설정, 같은 100만 스텝 예산으로 두 번 돌렸더니 성공률 12.5%/점수
33.46과 성공률 0%/점수 −1.60이 나왔다.** 차이는 SB3 `DQN` 생성자에 넘긴
학습 시드뿐이었다 — 평가 시드 40개는 고정돼 있었지만 학습 시드는 매번
난수였다. 즉 아래 "측정 결과"의 각 행은 **n=1** 샘플이다. 환경이
학습 가능하다는 판단도, 그 위에서 설계한 6라운드 커리큘럼도 이 n=1
숫자 하나에 의존하고 있었다.

이건 채점에도 직결된다. 학생 200명의 DQN 에이전트를 이 환경으로 채점하는
데, 시드만 바꿔도 성공률이 0%에서 12.5%로 뛴다면 성적이 실력이 아니라
운을 재는 것이다.

**그래서 `scripts/measure_baseline.py`는 이제 `--seeds N` (기본 3)으로
여러 학습 시드를 독립적으로 돌리고, 각 실행의 점수/성공률을 한 줄씩
찍은 뒤 평균·최솟값·최댓값과 "평균 DQN − 무행동" 분리도를 함께
보고한다.** 앞으로의 측정은 전부 이 방식으로 다시 재고, 여러 시드
없이 나온 숫자는 신뢰하지 않는다.

아래 "측정 결과"의 기존 표들은 전부 **n=1** (학습 시드 하나) 측정이다.
지우지 않고 남겨둔다 — 언제 무엇을 쟀는지의 기록 자체가 가치가 있다.
다만 그 숫자들을 근거로 결론을 내리지는 말 것.

## 측정 결과

### 2026-07-21 — 보상 재설계 이후 (`landing-easy`) — n=1

| 예산 | 정책 | 점수 | 성공률 |
|------|------|------|--------|
| — | 무행동 (추력 0) | 0.38 | 0.0% |
| — | 무작위 | −0.77 | 0.0% |
| 100k | DQN (lr 6e-4) | 0.17 | 0.0% |
| **1M** | **DQN (lr 6e-4)** | **33.46** | **12.5%** |

무행동 대비 분리: 100k에서 **−0.21**, 1M에서 **+33.07**.

참고로 손으로 짠 고전 PD 제어기는 60/60 성공에 평균 201.2점이다. 천장은
열려 있고, 학습 시간과 하이퍼파라미터 튜닝이 실제로 순위를 만든다.

### 재설계 이전 기록 (참고 — 이 보상은 더 이상 쓰지 않는다) — n=1

| 정책 | 점수 | 성공률 |
|------|------|--------|
| 무행동 | **36.6** | 0.0% |
| 무작위 | 29.2 | 0.0% |
| DQN 120k (lr 6e-4) | 32.2 | 0.0% |
| DQN 300k (lr 3e-4) | 30.4 | 0.0% |
| DQN 300k (lr 1e-3) | 34.7 | 0.0% |

목표가 지면에 있어 `1 - d_final/d_initial` 공식에서 중력이 거리를 공짜로
닫아 주었다. 자유낙하만으로 실패 점수의 80~89%를 받았고, 학습된 정책이
무행동보다 낮은 점수를 받았다.

## 재측정 방법

```bash
uv pip install -e ".[sb3]"
uv run python scripts/measure_baseline.py --preset landing-easy --steps 1000000 --seeds 5
```

프리셋을 바꾸거나 `reward.*`를 건드린 뒤에는 반드시 다시 잰다. `--seeds`는
최소 3 이상으로 — 학습 시드 하나짜리 측정(n=1)은 이 문서에 결과로
기록하지 않는다.
